# Fundamentos de diseño de interfaz — investigación del 2026-11-12

La base teórica del set de skills «Al milímetro» (`.claude/skills/milimetro` y sus seis hermanas). Felipe pidió «skills que diseñen
al milímetro y con base teórica, además de con full animaciones, cada componente, cada gráfico o cada texto que tenga el sistema».

- `informe-movimiento.md` — el informe sintetizado sobre motion: evidencia, normas, diez sistemas de diseño, práctica y bibliografía comentada.
- `notas/` — las notas de cada frente, con sus URLs y valores exactos: movimiento (4 archivos), tipografía, retícula y espaciado,
  color y contraste, visualización de datos, componentes y textos.

Cada afirmación lleva su nivel: **Evidencia** (estudio revisado por pares), **Norma** (WCAG, especificación, guía de plataforma) o
**Práctica** (tokens de sistemas de diseño, NN/g, design engineers). Lo que no se pudo verificar está marcado así en cada nota.
Es una foto del 2026-11-12: los sistemas de diseño cambian, y una cifra de aquí se vuelve a mirar en su fuente antes de una decisión grande.
