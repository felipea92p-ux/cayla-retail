Lo que decidiste (2026-11-09) y lo que falta construir

  • Quién puede crear: todos los que ven Recibir mercadería. No hace falta tener los módulos Proveedores ni Catálogo.
  • El proveedor nuevo pide poco: la razón social y, si se tiene, el RUC. Si se parece a uno que ya existe, la hoja pregunta antes de crearlo.
  • En la base: dos funciones propias de Recibir, una para el proveedor y otra para la marca, con el permiso de Recibir escrito en cada una. Así se hizo con la marca nueva de Mis compras. Las de Proveedores y Catálogo no se tocan.
  • Falta verificar: si la base acepta en este envío una prenda de un proveedor que no venía en la guía. También, que el campo «De qué proveedor» salga aunque la guía traiga un solo proveedor.
