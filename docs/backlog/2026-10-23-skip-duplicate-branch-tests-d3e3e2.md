## «Update branch» sin repetir pruebas (2026-10-23, ADR-0492) — lo que queda
- [ ] **Medir en una semana** cuántas corridas de PR se saltaron por la marca (log de «Qué toca el PR»: «este mismo árbol … ya pasó»). Si son pocas, el cuello sigue siendo `main` moviéndose: la única salida grande es la cola de fusión, que pide pasar el repo a una organización de GitHub (decisión de Felipe).
